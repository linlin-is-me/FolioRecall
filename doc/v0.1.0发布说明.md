## 实测与限制

历史 ONNX 开发对照中，完整检索请求 P50 为 PyTorch 19.33、FP32 8.62、int8 4.79 ms，预热 RSS 约 636／817／581 MiB。实际 FAISS 为四线程，原文单线程说明已更正，数值不变。FP32 五域指标与基线一致；int8 五域等权 nDCG 下降 0.005031，故默认选择 FP32，接受更高内存。这些是查询结果，不代表远程问答同比加速，也不与后续搜索单线程测量作严格同条件比较。完整条件见[ONNX记录](首版使用与评测.md#onnx-cpu-backends)。

四项扩展已完成：证据覆盖补查未改善整体覆盖；LLaVE 收益小且集中；多深度四层质量退化，均未接入产品默认。训练实现和结果保留，B3 尚未启动。

原单轮 A5 完成 240 项首次结果及助手评审，237 项结构合法；结构合法率不等于回答准确率。原 A6 六项真实使用及五轮多轮浏览器记录保留。五轮产生 25 次 API 请求，已知估算费用 0.455042 元；跨文档例遗漏就业报告，追问延续该遗漏，截图保留。语义评分保持 assistant、human=not_checked，独立人工复核为可选。

最终包已通过仓库外安装、依赖元数据、四条CLI、两次真实浏览器免费检索及三轮模拟生成器问答装配检查。两个服务各常驻加载一次，追问、重置、进度、引用和三轮复制／保存JSON一致，验证摘要随包提供。下载链接已实际点击，HTTP 200与内容一致性另行通过；浏览器自动化未返回下载事件，落盘状态尚未确认，作为审核局限保留。模拟输出只用于检查装配，不构成真实问答质量证据；本轮无新增生成 API 调用。复用已有依赖环境，不称全新机器安装验证。

本地单用户，会话刷新清空，不包含持久会话数据库或公网部署。可能遗漏事实、误读图表或引用不足证据，检索分数不能视为拒答概率。
